☁️ 구글 드라이브 백업

본인 구글 계정으로 로그인하면 내 기록을 내 구글 드라이브에 백업하고, 다른 기기에서도 불러올 수 있습니다. 각자 자기 계정·자기 드라이브에만 저장되며, 앱은 자신이 만든 백업 파일 하나(학생행동기록_백업.json)에만 접근합니다.

로그인 안 됨
구글 백업이 준비되어 있습니다. 아래 구글로 로그인만 누르면 바로 사용할 수 있어요.
지금은 파일을 직접 열어(로컬 파일) 실행 중이라 구글 로그인이 차단됩니다. 아래 “설정 방법”대로 앱을 웹 주소(https)나 http://localhost에 올린 뒤 사용하세요. 그 전까지는 아래 “파일로 백업”을 이용하시면 됩니다.
구글 드라이브 백업 — 최초 1회 설정 방법 (펼치기)
  1. 앱을 웹 주소로 준비 — 이 파일을 무료 호스팅(예: GitHub Pages)에 올리거나, 컴퓨터에서 http://localhost 로 여세요. (파일을 그냥 더블클릭한 file:// 상태에서는 구글 로그인이 안 됩니다.)
  2. 구글 클라우드 콘솔에서 새 프로젝트를 만듭니다.
  3. API 및 서비스 → 라이브러리에서 Google Drive API를 검색해 사용 설정합니다.
  4. OAuth 동의 화면을 구성합니다. 사용자 유형 외부 선택, 앱 이름 입력, 그리고 테스트 사용자에 본인 구글 이메일을 추가합니다. 범위(scope)는 별도 추가 없이 진행해도 됩니다.
  5. 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID를 선택하고, 애플리케이션 유형은 웹 애플리케이션을 고릅니다.
  6. 승인된 자바스크립트 원본에 이 앱의 주소를 그대로 추가합니다. 예: https://내계정.github.io 또는 http://localhost:8000 (경로 없이 도메인만).
  7. 생성된 클라이언트 ID(…apps.googleusercontent.com)를 복사해 위 입력칸에 붙여넣고, 구글 로그인을 누릅니다.
